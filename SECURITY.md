# Security Policy

> **Status:** REQUIRES-DECISION · **Verified:** 2026-09-20 · SchoolOS is **pre-production**; see [`docs/security/SECURITY-OVERVIEW.md`](docs/security/SECURITY-OVERVIEW.md) and [`docs/security/KNOWN-GAPS.md`](docs/security/KNOWN-GAPS.md).

## Reporting a vulnerability
**Contact: `REQUIRES-DECISION`.** No security contact address or private reporting channel has been designated by the project owner, and none is invented here. Until one is set, do not open a public issue containing exploit details; use GitHub's private vulnerability reporting for the repository (<https://github.com/zainknoman/SchoolOS>) if it is enabled by the owner.

## Supported versions
No versions are released or tagged. Only `main` is maintained.

## Scope notes
Known issues are already listed in `docs/security/KNOWN-GAPS.md`. Reports about items listed there are still welcome if they add new impact or a reproduction.
